## Customer Journey Map

| Phase of Journey | Stage 1: Enter Profile | Stage 2: Generate & Review Plan | Stage 3: Revise & Revisit |
|---|---|---|---|
| **Actions** <br> What does the customer do? | - Opens FitBuddy<br>- Enters username, ID, age and weight<br>- Selects goal and intensity | - Submits the form<br>- Reviews the seven-day workout plan<br>- Reads nutrition/recovery tip | - Gives natural-language feedback<br>- Reviews revised plan<br>- Reopens saved result later |
| **Touchpoint** <br> What part of the service do they interact with? | - Home form<br>- Validation messages | - Result page<br>- Generated plan<br>- Nutrition tip | - Feedback page<br>- Updated result<br>- Saved user/admin view |
| **Customer Thought** <br> What is the customer thinking? | - "Will this fit my goal?" | - "Is this practical for me?" | - "Can I change this without starting over?" |
| **Customer Feeling** <br> What is the customer feeling? | Curious, slightly uncertain | Hopeful and engaged | Relieved and in control |
| **Process Ownership** <br> Who is in the lead on this? | Backend validation and UI (Abdul Wahith M, Kamalesh T) | AI generation and persistence (Abdul Wahith M, Prasannavelan K) | Feedback, QA and UI (Bilu Besto H, Bharath Jeyakkumar S, Kamalesh T) |
| **Opportunities** <br> How can we improve this stage? | - Add more user preferences<br>- Add onboarding presets | - Add exercise illustrations<br>- Add progress visualization | - Add history/versioning<br>- Add wearable integration |
