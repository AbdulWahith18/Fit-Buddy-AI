# Technology Stack

{{HEADER:2 Marks}}

| Layer | Technology | Purpose |
|---|---|---|
| Language | Python | Application implementation |
| Web framework | FastAPI | HTML routes and JSON APIs |
| Server | Uvicorn | ASGI application server |
| Templates | Jinja2 | Server-rendered web pages |
| Validation | Pydantic | Input and API schema validation |
| ORM | SQLAlchemy | Database models and persistence |
| Database | SQLite | Local user/plan storage |
| AI | Google Gemini via `google-genai` | Workout, nutrition and revision generation |
| Testing | pytest + FastAPI TestClient/httpx | Automated application testing |
| Configuration | python-dotenv | Environment-based settings |
| Deployment | Dockerfile | Containerized execution |
