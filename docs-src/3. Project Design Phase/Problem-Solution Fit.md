# Problem-Solution Fit

{{HEADER:3 Marks}}

| User Problem | FitBuddy Solution |
|---|---|
| Generic fitness advice does not match individual inputs | User-specific seven-day plan based on age, weight, goal and intensity |
| Planning a week manually is time-consuming | AI generates a complete weekly routine |
| User needs change after seeing the plan | Natural-language feedback produces a revised plan |
| Previous version can be lost during editing | Original plan is retained separately |
| AI service may be unavailable | Model fallbacks, retry handling and mock mode |
| Users want integration options | HTML application and JSON API |
| Saved plans need retrieval | SQLite persistence and result/admin views |
